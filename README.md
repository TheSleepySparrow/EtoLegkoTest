# Benchmark Script

Консольный скрипт для тестирования скорости загрузки веб-ресурсов.

## Описание

Скрипт выполняет серию из 10 последовательных GET-запросов по указанному URL, измеряет время ответа и объем полученных данных, после чего выводит статистику:
- Среднее время запроса
- Общий объем скачанных данных
- Средний объем данных за запрос
- Скорость скачивания

## Требования

- Node.js версии 26 или выше

## Установка

Скрипт использует только встроенные модули Node.js, дополнительная установка зависимостей не требуется.

## Запуск
```bash
node benchmark.js
```

После запуска скрипт запросит URL для тестирования. Введите полный адрес, включая протокол (http:// или https://).

## Единицы измерения

### Время запроса

- Миллисекунды (мс) - одна тысячная доля секунды
- Используется для измерения времени отправки запроса до получения полного ответа

### Объем данных

- Килобайты (КБ) - 1 КБ = 1024 байт
- Измеряется только полезная нагрузка (body) HTTP-ответа
- Заголовки ответа не учитываются в объеме данных

### Скорость скачивания

- Мегабайты в секунду (МБ/с) - 1 МБ = 1024 × 1024 байт
- Рассчитывается как: общий объем данных (в МБ) / общее время всех запросов (в секундах)

## Обработка ошибок

### Проверка URL

Перед началом тестирования скрипт проверяет валидность URL:
- URL должен начинаться с http:// или https://
- При некорректном URL скрипт завершает работу с сообщением об ошибке

### Проверка доступности

Первый запрос используется для проверки доступности ресурса:
- Если первый запрос завершился с ошибкой, скрипт выводит сообщение и завершает работу
- Дальнейшие расчеты не производятся

### Обработка ошибок во время тестирования

- Если запрос завершился с ошибкой (таймаут, сетевая ошибка, HTTP код не 200), он пропускается
- Неудачные запросы не включаются в расчеты статистики
- Скрипт продолжает выполнение и выводит статистику только по успешным запросам
- Если все запросы завершились с ошибкой, выводится соответствующее сообщение

### Таймаут

- Максимальное время ожидания ответа: 15 секунд
- При превышении таймаута запрос прерывается и считается неудачным

## Особенности реализации

- Используется метод HTTP GET
- Измерение времени с высокой точностью через process.hrtime.bigint()
- Последовательное выполнение запросов (ожидание ответа перед отправкой следующего)
- Поддержка как HTTP, так и HTTPS протоколов
- Подсчет только полезной нагрузки (body), без учета заголовков
